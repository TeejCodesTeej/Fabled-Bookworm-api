## User Stories

As a user, I want to be able to login to the site, So I can access my book lists

As a user, I want to be able to collate my books that I have read and want to read

As a user, I want to leave a review for a book that I like or don't like

As a user, I want to see if a book is part of a series So that I can read the series if I want

As a admin user, I would like to add, update or delete books
